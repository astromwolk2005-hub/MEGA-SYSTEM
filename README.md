# NEXUS: Орбитальный Протокол (Fabric 1.21.1)

Глобальный техно-магический мод для Minecraft 1.21.1:
- **Орбитальный Лазер** — целеуказатель вызывает гигантский ионный удар с орбиты.
- **Гравитационная Пушка** — захватывай любых мобов (ПКМ) и швыряй их с взрывом (присесть + ПКМ).
- **Граната Сингулярности** — создаёт мини-чёрную дыру, затягивающую и аннигилирующую всё вокруг.
- **Кибер-Ядро (Экзоскелет)** — кастомный HUD + переключение режимов на `[R]` (Реактивный Ранец, Гипер-Скорость, Боевой Щит) и активация импульса на `[G]`.
- **Орбитальная Станция** — личное карманное измерение в космосе (Телепортер Нексуса или `/nexus station`).

## Сборка на GitHub
Просто залей файлы из архива в репозиторий на GitHub -> вкладка **Actions** -> скачай готовый `.jar` из **Artifacts**.
